Projects

Sparrow

A campaign-based cold-outreach tool built for students reaching out to startups. Sources contacts from VC portfolio databases, generates an AI-personalized email per recipient grounded in a per-company research report, and sends through the user's own Gmail. Stack: TypeScript, React, Prisma, PostgreSQL, Supabase, Anthropic API.

Spectre

A real-time 1v1 fighting game played with your phone as a motion controller. The camera tracks punches and kicks via pose estimation and you watch your silhouette fight. Stack: Rust, TypeScript, React, MediaPipe, WebSockets, Docker.

CVE Intel

A natural-language search and analysis engine over the CVE database. Ask a question in plain English and get back semantically relevant CVEs with a briefing and citations. Stack: Python, TypeScript, Next.js, FastAPI, PostgreSQL, pgvector, AWS Lambda, Terraform, Anthropic API.

Podium

A browser-based presentation practice tool. Records webcam and microphone input, then scores delivery on eye contact, filler words, and pacing using on-device ML and CV models. Stack: TypeScript, React, MediaPipe, Whisper.wasm, IndexedDB.

Philly Vibe Map

An interactive map of Philadelphia neighborhoods colored by the dominant vibe derived from NLP analysis of 1.1 million Yelp reviews, with a temporal slider showing change year over year. Stack: Python, TypeScript, React, FastAPI, BERTopic, DistilBERT, sentence-transformers, MapLibre GL.

Auto Shorts

A CLI pipeline that produces short-form videos end to end: scrapes and scores content from Reddit and X, generates scripts and video, and uploads to YouTube Shorts and Instagram Reels. Stack: Python, FFmpeg, Playwright, SQLite, Anthropic API, ElevenLabs, YouTube API, Instagram Graph API.

AlgoTrader Bridge

A trading bridge that receives TradingView webhook signals and routes them to Interactive Brokers TWS for execution, with a live dashboard of trading activity. Stack: Python, FastAPI, SQLite, SQLAlchemy, IBKR TWS API, Docker.

SkyOps

An AI-powered charter flight operations platform that parses booking requests from email and automates quoting, routing, and pricing. Stack: TypeScript, React, Next.js, Anthropic API, PostgreSQL.

VulnScan

A CLI tool that analyzes Python source for security vulnerabilities using AST traversal, with AI-powered fix suggestions via the Claude API. Stack: Python, Click, Anthropic API.
